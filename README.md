# Patrones de Programación - Plantillas para Parcial

Plantillas Java 8+ de los 8 patrones del parcial:

- Bridge
- Strategy
- Builder
- Chain of Responsibility
- Observer
- Flyweight
- Repository
- Dependency Injection

Cada carpeta es independiente y contiene un ejemplo sencillo compilable.

## Compilar una carpeta

Desde la carpeta del patrón:

```bash
javac *.java
java Main
```

## Idea para el parcial

Primero identifica la intención del enunciado y luego adapta nombres y lógica. No es necesario copiar el ejemplo literal: conserva la relación entre las clases del patrón.
